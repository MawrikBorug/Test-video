# Test-video · торрент-стенд

Стенд: https://test-video-taupe.vercel.app/

Следующий облачный тест: [развернуть исполнитель на Render Free](https://render.com/deploy?repo=https://github.com/MawrikBorug/Test-video).
[Пошаговая инструкция и ограничения](docs/RENDER_SETUP.md). Работоспособность
торрент-доставки на Render пока не проверена; это не подтверждённая замена.

**В работе. Просмотр обязательной подборки пока не подтверждён.** Поиск,
контрольный TCP-торрент и коммерческие раздачи имеют разные доказательства.

Цепочка: Comet / TorrentsDB → infohash → libtorrent TCP/UDP → проверка полного
info dictionary и файла сезона/серии → ffprobe (реальные дорожки) → FFmpeg →
HLS H.264/AAC → собственный HTMLVideoElement. Iframe, Lift, прямые фильмы из
других онлайн-кинотеатров и постоянный ноутбук-сервер не используются.

## Что подтверждено

- В опубликованном backend выполнены 48 поисковых запросов: 24 комбинации
  произведения/серии × Comet/TorrentsDB. Все вернули torrent-кандидаты.
  Это не подтверждение медиадоставки.
- Контроль на собственном сгенерированном видео: настоящий libtorrent TCP,
  SHA-1 частей, запуск до полного скачивания, два аудиопотока и декодируемый
  HLS-сегмент после перемотки на 120 секунд.
- В Chromium/Linux: собственный плеер, выбранная дорожка, дальняя перемотка,
  смена дорожки и качества 720→480 с сохранением позиции, автоматический
  переход после намеренного отказа и настоящее событие ended у контроля.
  Поисковая выдача этого теста синтетическая; медиаданные получены настоящим
  торрентом от временного loopback-сидера. Контроль не доказывает WAN/iPhone.
- 20 исследовательских сопоставлений серий проверены против сохранённых
  info dictionary: infohash, полный fileIdx (включая не-видео), путь и длина.

## Сервер и условия

Исходники — `MawrikBorug/Test-video`. UI и Python API опубликованы в отдельном
проекте `test-video` команды Vercel `korotkowwww-4729`. Автопривязка GitHub не
подключилась: Vercel требует GitHub Login Connection. Сейчас публикация идёт
прямой загрузкой исходников с указанием SHA; GitHub содержит те же исходники.

Vercel предоставляет вычисления и исходящий трафик. Платный тариф не включался,
карта не запрашивалась. Лимиты бесплатного плана и доступный остаток квоты не
равны безлимитной бесплатной медиадоставке. Для каждой функции задан предел
300 секунд. Кэш торрента ограничен 256 МиБ в Vercel; при ротации экземпляра
файл и metadata восстанавливаются из подписанного задания. Это может дать
задержку; длинный непрерывный фильм на этой платформе пока не подтверждён.
Локальный Docker-вариант ниже — возможность размещения, не выбранный сервер
владельца. Публичных чужих TorrServer, debrid-ключей или платных API нет.

Поиск предоставляют публичные community-хосты `comet.feels.legal` и
`torrentsdb.com`. Условия длительной эксплуатации/SLA не установлены.
Отсутствие ключа не обещает бессрочную бесплатность. Их дубликаты объединяются
по infohash+fileIdx с сохранением происхождения.

## Воспроизведение и диагностика

Выберите произведение → сезон/серию → «Найти источники» → «Проверить и запустить».
Очередь проверяет до 8 раздач. Metadata timeout, неоднозначный файл,
неподтверждённый русский звук, ошибки FFmpeg и fatal HLS приводят к следующей
раздаче. Пустой/неполученный ответ не превращается в successful playback.

Русская дорожка определяется по прочитанным ffprobe language/title, а не
флагу в описании релиза. Качества 480/720/1080 — серверная подготовка H.264 без
увеличения исходного разрешения. Переключение дорожки/качества перезагружает
поток с прежней позицией. Между разными релизами монтаж может различаться.
В HDR→SDR пока нет отдельной проверенной цветокоррекции.

«Факты сеанса» и JSON содержат запросы, HTTP/ошибки, байты, metadata и
trusted-события видео. Подписанные задания, временные URL, cookies и ключи
не экспортируются. Нулевые байты — измеренный ноль, null — не измерено.

Физический iPhone Safari, установленная PWA, PiP/фон и полный просмотр всех
десяти произведений: **NOT_RUN**. Chromium и контрольные тоны не подтверждают
прослушивание русской речи на телефоне.

## Локальная проверка разработчика

```sh
npm ci
python3 -m pip install -r requirements.txt
# Нужны ffmpeg и ffprobe; npm-пакеты содержат Linux-бинарники для Vercel.
python3 -m unittest tests.test_backend -v
npm test
npm run build
python3 -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
npm run dev
```

Браузерный контроль запускается отдельно; производственный API не импортирует
его и не имеет скрытого маршрута с контрольным фильмом:

```sh
python3 -m tests.control_server
npm run dev
npm run test:browser
```

`scripts/probe_live.py URL` проверяет настоящую поисковую матрицу.
`python3 -m scripts.probe-play slovo` проверяет реальные torrent-кандидаты
через опубликованный backend, сохраняет только диагностику, удаляет сегменты
после ffprobe. Контрольные и коммерческие результаты — в `evidence/` с разными
`kind`; ошибочная ранняя проба адреса помечена `INVALID_PROBE_TARGET_CLIENT_BUG`.

Исследование 22–23.10.2026 прочитано из предоставленной папки Drive:
REPORT.md, CONCLUSION.md, STAND_HANDOFF.md, EVIDENCE.zip. Снимки metadata имеют
фиксированные SHA-256 в `backend/metadata-index.json`; их загрузка на сборке
проверяет контрольную сумму, runtime проверяет исходный infohash.
