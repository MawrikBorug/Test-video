# Бесплатный проверочный исполнитель на Render

Это следующий эксперимент после отказов текущего Vercel-исполнителя.
Сборка контейнера и наличие библиотек не доказывают доступность торрент-пиров
на Render. Проверка там ещё не выполнена. Приёмка подборки остаётся 0/10.

1. Откройте [развёртывание Test-video](https://render.com/deploy?repo=https://github.com/MawrikBorug/Test-video).
2. Войдите или зарегистрируйтесь в Render. Можно использовать GitHub.
3. В предварительном просмотре должен быть **один** Web Service
   `test-video-executor`, план **Free**, стоимость вычислений **$0**.
   База данных, постоянный диск, платный worker и платный тариф не нужны.
4. Подтвердите Deploy Blueprint. Дождитесь состояния Live.
5. Пришлите публичный HTTPS-адрес сервиса вида `https://….onrender.com`.
   Для HTTP-проверок нам не нужны пароль, API key или SSH-ключ.

Если регистрация или развёртывание именно вашего аккаунта потребует карту,
остановитесь и сообщите текст запроса. Карту не добавляйте и план не повышайте.

Интерфейс может остаться на прежнем адресе Vercel. У него уже есть поле
«Сервер торрент-доставки» для HTTPS-адреса внешнего исполнителя. После проверки
нового сервера его можно подключить к интерфейсу без смены архитектуры плеера.
Контейнер также содержит собственную копию интерфейса.

Для этого репозитория включён автодеплой ветки main. Последующие проверенные
изменения в Test-video смогут обновлять этот сервис. Секрет подписи заданий
Render сгенерирует самостоятельно; он не включается в код и экспорт.

## Условия, проверенные по документации 24.10.2026

Render документирует бесплатные Web Services и работу без добавленного способа
оплаты: при исчерпании квоты сервис приостанавливается вместо дополнительного
списания. Free засыпает после 15 минут без входящих запросов и может
приостанавливаться из-за большого объёма инициированного им трафика. Диск
эфемерный. Это ограниченный тестовый ресурс, без гарантии длительного просмотра.
Успех исходящего BitTorrent и скорость FFmpeg здесь пока неизвестны.

Источники: [Free](https://render.com/docs/free),
[FAQ о начислениях без способа оплаты](https://render.com/docs/faq),
[Deploy to Render](https://render.com/docs/deploy-to-render),
[Blueprint](https://render.com/docs/blueprint-spec).

В render.yaml явно выбрано plan: free, нет диска и баз данных. Кэш ограничен
256 МиБ, разрешён один torrent-сеанс. Dockerfile собирает frontend из исходников
и устанавливает libtorrent/FFmpeg; локальный dist для развёртывания не требуется.
