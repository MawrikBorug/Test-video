# Stremio как движок нашего плеера: облачный тест

**Это запуск того же стенда в облаке, с воспроизведением в его собственном
HTML-плеере. Приложение Stremio на iPhone устанавливать не требуется.**

Цепочка: Comet/TorrentsDB → infohash → приватный Stremio EngineFS → независимая
проверка info dictionary и файла серии → ffprobe/FFmpeg → HLS → наш плеер.
Выбор дорожки и качества, перемотка и автоматический переход после отказа
остаются в стенде. Iframe и переходов на другой видеосайт нет.

## Запуск

1. Для проверки длинного фильма перед созданием машины откройте
   [настройки Codespaces](https://github.com/settings/codespaces) и установите
   **Default idle timeout → 240 минут**. Настройка применяется к новым машинам.
2. Откройте [создание Codespace для Test-video](https://codespaces.new/MawrikBorug/Test-video).
3. Войдите в свой GitHub, выберите `main` и машину **2-core**. Оставьте
   конфигурацию `Test-video · Stremio executor`. Создайте **один** Codespace.
   Карту и платные планы для этого опыта добавлять не нужно.
4. Дождитесь окончания установки зависимостей. Скрипты сами собирают стенд,
   скачивают официальный Stremio EngineFS 4.20.17 с проверкой SHA-256 и
   запускают оба процесса. Первоначальная сборка может занять несколько минут.
5. Во вкладке **Ports** нужен порт **8000**. Скрипт пробует открыть его
   публично. Если GitHub не разрешит это скрипту, нажмите правой кнопкой
   по 8000 → **Port Visibility → Public**. Протокол самого порта оставьте HTTP:
   внешнюю HTTPS-ссылку предоставляет GitHub.
6. Откройте адрес вида `https://ИМЯ-8000.app.github.dev/` на iPhone. Это весь
   наш стенд: каталог, источники и собственный плеер. Пришлите этот публичный
   адрес для внешних проверок. Пароль, GitHub token, Apple ID и SSH-ключ не нужны.

Порты Stremio 11470/12470 **не публикуются**. Это внутренний движок,
его общий API загрузки произвольных торрентов не является публичным API стенда.
Наш `/api/open` принимает только hash из свежей выдачи выбранного произведения.

Если хочется использовать прежнюю страницу Vercel, в ней откройте
«Факты сеанса → Сервер торрент-доставки» и вставьте новый HTTPS-адрес.
Сначала удобнее проверить страницу самого Codespace: там API и плеер
находятся на одном origin.

## Ресурсы и ограничения

Вычисления и HTTPS-проброс предоставляет **GitHub Codespaces**. Для личного
GitHub Free официально включены 120 core-hours, то есть до **60 часов на
2 ядрах за месяц**, и **15 GB-month хранения**. Остаток конкретного аккаунта
из этой сессии не проверен. При отсутствии способа оплаты после расходования
квоты Codespaces блокируется до следующего периода.

Это среда разработки и проверки стенда, а не обещание постоянного бесплатного
хостинга. По умолчанию она останавливается после **30 минут отсутствия
взаимодействия с редактором/терминалом**: одни запросы плеера к порту не
гарантируют сброс таймера. Для длинного прогона можно установить 240 минут
в [личных настройках Codespaces](https://github.com/settings/codespaces).
Одно непрерывное выполнение ограничено 12 часами. После остановки возобновите
существующий Codespace — создавать новую машину каждый раз не нужно.

После проверки остановите Codespace на https://github.com/codespaces.
Остановленный Codespace продолжает учитывать хранение; ненужный удалите.
В коде нет искусственного keepalive для обхода остановки.

Исполнитель ограничен одной сессией и 512 МиБ полученных данных до ротации
торрент-движка. Stremio запускается с `uploads: 0`; выбор случайного полного
фильма для фоновой загрузки не производится. Неактивная сессия закрывается
через пять минут. Повторное получение частей после ротации может задержать
перемотку и требует фактической проверки на внешней раздаче.

## Проверки и диагностика

- `/api/health` сообщает `Stremio EngineFS TCP/UDP` и `engineReady: true` только
  после ответа локального движка. Это **не** признак полученных медиабайтов.
- «Факты сеанса» содержит проверенный файл серии, реальные дорожки, байты,
  пиры, события видео и причину перехода к следующему источнику.
- При ошибке запуска смотрите `.runtime/cloud.log`, `.runtime/stremio.log`,
  `.runtime/backend.log`. Для повторного запуска: `bash scripts/cloud-start.sh`.
- `.runtime/playback-secret` — локальный ключ подписи. Он не входит в Git
  и не нужен для диагностики; не копируйте его в сообщения.

В Chromium/Linux на собственном 150-секундном ролике проверены реальные TCP,
получение metadata через BEP9, воспроизведение в нашем плеере, дальняя
перемотка, смена дорожки, 720→480, автоматический переход и событие `ended`.
Поисковая выдача и аудиотона этого опыта синтетические; это **не проверка
русской речи или десяти обязательных произведений**.

Внешние торрент-пиры **на Codespaces**, полный просмотр подборки и физический
iPhone/PWA пока **NOT_RUN**. Поддержка протокола и локальный контроль не
доказывают доступность внешней сети конкретной машины.

На момент подготовки GitHub вернул `403 Resource not accessible by integration`
для `/repos/MawrikBorug/Test-video/codespaces/new` и `/codespaces/machines`.
Обычный доступ к исходникам разрешён, но доступ к созданию Codespace из
подключённой интеграции не предоставлен. Поэтому создание машины
выполняет владелец аккаунта в браузере (пункт 3); это ограничение доступа, а не
необходимость установки чего-либо на ноутбук.
